# English edition

This directory contains the English edition of the consolidated chapters in
`chapters/`.

The Italian chapter is the primary editorial source. An English counterpart is
created or updated only when the user explicitly requests a specific chapter in
English. Reaching a stable checkpoint does not trigger translation
automatically. Filenames, section numbering, diagrams, formulas, code snippets,
comments, docstrings, and expected outputs must remain aligned across the two
editions.

If translation exposes an ambiguity, the Italian source is corrected first and
the English version is then updated from that corrected checkpoint.
